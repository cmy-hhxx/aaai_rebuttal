# 表格附录 - 框架级基线比较（97 seeds / 1,440 道盲评）

所有表格为定宽 ASCII，可直接粘进邮件、LaTeX 的 `verbatim` 或终端。数字不是手抄的：T1-T7 由 [final_experiment/analysis/rebuttal_tests.py](final_experiment/analysis/rebuttal_tests.py) 从冻结产物（逐题标签、盲评 key、逐请求 token 账本）算出，中间量存在 [final_experiment/run/analysis/rebuttal_tests.json](final_experiment/run/analysis/rebuttal_tests.json)；T0 取自配置文件与 `run/manifest.json`。所有表由 [tools/make_tables_ascii.py](tools/make_tables_ascii.py) 渲染。

## 口径定义

- **valid**：盲评模型判定为 `valid`（题目完整、可解、规范答案与题面一致）。
- **dependent steps / depth**：`depth_score` 0-4，指解题所需的最小依赖推理步数，不是文本长度。
- **near-duplicate**：同一 seed 内题对的字符 4-gram Jaccard 相似度 ≥ 阈值。
- **identical tag sets**：盲评给题对中两道题分配的推理操作集合（或约束类型集合）完全相同。
- **certificate score**：盲评对标准化求解证书的 `explanation_score`（0-4）。
- **tokens per valid item**：生成 token ÷（有输出的题数 × 题级有效率），PF 按每个 generator 摊 200 个实例计。
- **配对差**：先算每个 seed 的差值再取均值；区间为 2,000 次 seed bootstrap 的 95% 百分位区间；p 为 Wilcoxon 符号秩检验，对本次全部 21 项检验做 Holm 校正。

## T5 - 证书分是深度的函数

```
+---------------+-----------------+------------------------+
| typical depth | n (valid items) | mean certificate score |
+---------------+-----------------+------------------------+
| 0 steps       |              10 |                   3.60 |
| 1 step        |             122 |                   3.73 |
| 2 steps       |             229 |                   3.69 |
| 3 steps       |             385 |                   3.22 |
| 4 steps       |             105 |                   2.19 |
+---------------+-----------------+------------------------+
```

仅统计有效题（n = 851）。合并 r = -0.33、ρ = -0.29；组内分别为 PF -0.31、B2 -0.32、B1 -0.29。深度越高的题越难写出满分证书，三条流水线幅度一致；因此证书分不用于支持任何流水线，正文按深度分层报告。
